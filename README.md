
# 💰 Student Expense Tracker

A beginner-friendly Python web application that helps students
record daily expenses and understand their spending habits.

## Features

- Add expenses with dates, categories, descriptions, and amounts.
- Save expense records locally in a CSV file.
- View total spending and number of transactions.
- Visualize spending by category and date.
- Filter expenses by category.
- View recent transactions.

## Technologies Used

- Python
- Streamlit
- Pandas

## Installation

1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Install the required libraries:

   ```bash
   python -m pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   python -m streamlit run app.py
   ```

5. Open the local URL displayed in your terminal.

## Project Structure

- `app.py` — Main application.
- `requirements.txt` — Required Python libraries.
- `README.md` — Project documentation.
- `.gitignore` — Files excluded from Git.

## Data Storage

Expense records are saved locally in `expenses.csv`.
Personal expense data should not be uploaded to GitHub.
